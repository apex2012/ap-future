# AP Future

# 13 · Engineering Standards

**Version:** 1.0.0  
**Status:** Official  
**Owner:** AP Future  
**Last Updated:** 2026-08-03

## Principles
Simplicity, reusability, maintainability, consistency, scalability, and documentation first.

## Code
React + TypeScript, PascalCase components, camelCase variables, UPPER_SNAKE_CASE constants, semantic HTML, no duplicated components, and no inline styling unless unavoidable.

## Targets
Lighthouse categories ≥95, WCAG 2.2 AA, no console errors, optimized images and bundles.

## Final Principle
Engineering excellence is measured by maintainability, not code volume.
