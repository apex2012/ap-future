## Purpose

This repository is the official source of truth for AP Future product, page, brand, content, engineering, search, AI, UI, and writing decisions.

## Product

AP Future is a premium international education platform for AP Courses, Digital SAT Preparation, University Planning, educational Resources, and responsible AI-assisted learning.

## Core Rules

- Education before marketing.
- Documentation before implementation.
- Reuse before creating.
- Quality before speed.
- AI assists; humans decide.
- Never invent undocumented features.

## Technology Baseline

React, TypeScript, Vite, Tailwind CSS, Lucide React, light Framer Motion, Markdown/MDX, GitHub, and Netlify.

Version 1 excludes a CMS, database, authentication, payments, portals, and an AI tutor.
